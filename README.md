# SEL 成長島 Mind Island

3D 社會情緒學習（SEL）互動小島。用瀏覽器開啟 `index.html` 即可（需連網載入 three.js）。

## 內容
- 八個區域：情緒灣、平靜峰、共感村、橋樑港、抉擇森林、迴音谷、願景塔、雙贏城堡
- 三種角色：患者（垂耳兔）、引導者（小鹿）、解決問題者（小熊），可自由行走
- 玩法：情緒溫度計、後果鏡子、善行徽章、暴風雨襲擊橋樑港的團隊事件
- 完成任務會在角色頭頂放煙火（可在畫面下方關閉）
- 點擊村民會出現 SEL 小情境，不同角色看到不同的選項與回饋

## 操作
- 電腦：WASD／方向鍵移動，拖曳轉視角，滾輪縮放，E 互動
- 手機：左下角搖桿移動，雙指縮放，單指拖曳轉視角
- 點地面或區域牌子，角色會自動走過去

## 上傳到 GitHub Pages
1. 在 GitHub 建立公開倉庫（例如 mind-island）
2. 上傳 `index.html` 和 `README.md`
3. Settings → Pages → Deploy from a branch → main / (root)
